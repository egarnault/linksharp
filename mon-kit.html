L'installer

  2. Les instructionsCopiez le contenu de « 1-Instructions » dans les instructions du projet.
  3. Les autres fichiersAjoutez « 2-La-methode », « 3-Messages-a-copier » et « 4-Suivi » dans les fichiers du projet.

Ensuite, chaque matin : « Fais-moi le point ». Vous relisez, vous validez, vous envoyez vous-même.
