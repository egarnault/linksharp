Comment ça marche

Trois étapes, dix minutes

  1. Décrivez votre offre

    L'IA propose trois profils de clients idéaux, avec les décideurs à viser et les signaux d'achat vérifiables.

  2. Réglez l'envoi

    Pays, langue, plafond de mails par jour, séquence de relances, outils. Fuseau, jours fériés et mentions légales se règlent seuls.

  3. Installez dans Claude

    Vous récupérez les skills et les tâches planifiées, réécrits pour votre secteur, avec la checklist d'installation.

Garde-fous

Automatisé, jamais incontrôlé

Ces règles sont écrites dans chaque système généré. L'IA peut les préciser, jamais les retirer.

  • Aucun envoi sans votre « go »
  • Plafond de mails par jour, 2 minutes entre deux envois
  • Aucun email, numéro ou signal inventé
  • Désinscription simple dans chaque mail
  • Une seule personne par entreprise, dédoublonnage par domaine
  • Rien n'est supprimé dans vos outils

Votre accès à l'IA

Le site est gratuit : l'IA fonctionne avec votre propre clé d'API Anthropic, à créer sur console.anthropic.com (rubrique « API Keys », avec un petit crédit). La clé reste dans votre navigateur et n'est envoyée qu'à Anthropic. Une génération complète coûte moins d'un centime avec Haiku, environ 0,10 $ avec Sonnet.

Le site s'arrête de lui-même avant de dépasser ce plafond. Pour une garantie totale, réglez aussi une limite de dépense dans la console Anthropic.
